# CodSoft Internship – Task 2
## Movie Rating Prediction with Python

This project focuses on predicting movie ratings using Machine Learning and Python.

The model uses features such as Genre, Director, Actors, Year, and Duration to estimate movie ratings.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

### Machine Learning Algorithm
Random Forest Regressor

### Project Steps
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Rating Prediction

### Conclusion
This project demonstrates the application of Machine Learning regression techniques to predict movie ratings based on historical movie data.
